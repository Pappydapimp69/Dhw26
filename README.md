# dhw26 — Denton Halloween 2026

One-page guide to the **31 Days of Denton Halloween** (Oct 2026). Open `index.html` in a browser — no build step.

- `events.js` — all event data. Add/edit entries there; fields are documented at the top.
- Events with no official detail page show "No official page" plus a **Source** link to wherever the info was found.
- `verified: false` marks events with only one secondary source or conflicting dates.

Main sources: dentonhalloween.com, cityofdenton.com calendar, Denton Record-Chronicle, dentondayofthedeadfestival.com, Prekindle (Big Top Tent), TWU, Denton Enterprise Airport, dentoncommunityvoice.com.

Last compiled: 2026-10-09.
